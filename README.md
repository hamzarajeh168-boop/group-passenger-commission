# شهم - جروب نقل ركاب

تطبيق مستقل لإدارة محافظ الكباتن وقواعد عمولة طلبات الجروب.

## التشغيل

```bash
npm install
npm start
```

افتح `http://localhost:4000/control-room`. كلمة السر المحلية الافتراضية `shahm-2026`، ويستحسن تغييرها عبر متغير البيئة `ADMIN_KEY`.

صفحة جرد الكابتن متاحة عبر `http://localhost:4000/captain`. يدخل الكابتن برقم هاتفه أو الكود العشوائي الظاهر عند إنشاء الحساب، وتعرض الصفحة الرصيد وسجل الشحن والخصومات والإحصائيات بصلاحية قراءة فقط.

## النشر

للنشر على Render استخدم:

- Build Command: `npm install`
- Start Command: `npm start`

للتجربة المحلية، يستخدم شهم Baileys افتراضيًا بدل Green API. شغّل `npm install` ثم `npm start`، وامسح رمز QR الظاهر في الطرفية من WhatsApp المرتبط بالكابتن الإداري. ستُحفظ جلسة الربط في `auth_info`، ولا ترفع هذا المجلد إلى GitHub أو Render.

يمكن تعطيل Baileys والعودة إلى Green API عبر:

`BAILEYS_ENABLED=false`

عند استخدام Baileys يجب أن يكون رقم WhatsApp المرتبط أدمن في الجروب حتى يستطيع إزالة الكابتن عند عدم كفاية الرصيد.

أضف الأسرار من Environment Variables فقط عند استخدام Green API:

- `ADMIN_KEY`
- `GREEN_API_INSTANCE_ID`
- `GREEN_API_TOKEN`
- `GREEN_API_URL` (اختياري، والقيمة الافتراضية `https://api.green-api.com`)

بعد النشر يكون Webhook:

`https://YOUR-RENDER-DOMAIN/webhook/group`

يجب أن يكون رقم Green API أدمن في الجروب حتى يستطيع إزالة الكابتن عند عدم كفاية الرصيد. التخزين الحالي محلي للتجربة؛ يلزم تخزين دائم قبل التشغيل التجاري.

لا تتم معالجة أي رسالة أو تفاعل إلا إذا كان `Group ID` القادم من Green API مطابقًا تمامًا للـ `Group ID` المحفوظ في غرفة الإدارة. الأحداث القادمة من أي جروب آخر يتم تجاهلها دون حفظ أو خصم.

## ربط الأحداث

يستقبل المسار `POST /webhook/group` أحداث الرسائل والتفاعلات. يجب إرسال رسالة الطلب أولًا، ثم Reply يحتوي `replyTo` على رقم الرسالة الأصلية، ثم Like يحتوي رقم الـ Reply ورقم هاتف الكابتن. لا يخصم النظام مرتين من نفس التفاعل. إذا كان الرصيد أقل من العمولة، لا يتم الخصم ويطلب النظام إزالة رقم الكابتن من الجروب عبر Green API بدل إزالة التفاعل.

لإزالة الرقم فعليًا يجب أن يكون رقم شهم أدمن في الجروب، وتُضبط المتغيرات السرية `GREEN_API_INSTANCE_ID` و`GREEN_API_TOKEN`، مع `groupId` في غرفة التحكم. إذا لم تضبط هذه القيم، يسجل النظام سبب عدم تنفيذ الإزالة بدل الادعاء بأنها تمت.

الربط الحقيقي مع WhatsApp يحتاج إعدادات Meta الرسمية وتوكنًا آمنًا في متغيرات البيئة؛ لا توجد أسرار داخل المشروع.
